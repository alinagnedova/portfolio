# Портфолио Алины Гнедовой

Готовый статический сайт для GitHub Pages. Сборка и установка зависимостей не нужны.

## Публикация через браузер

1. Создайте новый публичный репозиторий на GitHub, например alina-portfolio.
2. Распакуйте ZIP на компьютере.
3. В репозитории выберите Add file → Upload files.
4. Загрузите содержимое папки: index.html должен быть в корне репозитория, рядом со style.css, case.css, contact.css, contact.js, папками cases и img. Не загружайте сам ZIP.
5. Сохраните файлы кнопкой Commit changes.
6. Откройте Settings → Pages.
7. В Source выберите Deploy from a branch.
8. В Branch выберите main, папку / (root), нажмите Save.
9. Дождитесь успешного завершения публикации во вкладке Actions. Адрес сайта появится в Settings → Pages.

Если основная ветка называется иначе, выберите её вместо main.

## Проверка на компьютере

Откройте index.html в браузере. Переходы между кейсами и изображения используют относительные пути.
Для загрузки внешнего шрифта нужно подключение к интернету; без него используется системный шрифт.
Копирование почты работает на HTTPS; для локального просмотра предусмотрены выделение адреса и резервное копирование.

## Как обновлять

Замените изменённые файлы в репозитории и сохраните Commit changes. GitHub Pages опубликует обновление автоматически.
Не переименовывайте файлы и папки без обновления ссылок.

## Состав

- index.html — главная страница
- style.css — стили главной
- case.css — стили кейсов
- contact.css и contact.js — окно почты и часы по московскому времени
- cases/ — шесть страниц проектов
- img/ — фотографии и макеты
- .nojekyll — отключение обработки Jekyll; при загрузке через браузер скрытый файл может не попасть в репозиторий, для текущего сайта это не препятствие

Сайт не требует ключей API, сервера или платных сервисов.
